# Jasmin Portfolio Showcase

This is my personal showcase portfolio, built with **Vite**, **React**, **Tailwind CSS** and **Framer Motion**.

I created this project as a digital scrapbook for my ICT Media Design semester. The portfolio shows who I am, what I create and how I develop as a designer and front-end developer.

## About

I wanted my portfolio to feel different from a standard showcase website. Instead of only placing projects on a clean page, I chose a romantic vintage scrapbook style with soft colors, paper textures, envelopes, stamps and playful details.

The idea is to make visitors feel like they are opening my creative archive. Every section should tell a small part of my story, from who I am to the projects I worked on.

## Tech Stack

This project is built with a modern front-end setup. I used **Vite** because it is fast and easy to work with during development. **React** helps me build the portfolio in reusable components, which makes the project easier to improve later. For styling, I use **Tailwind CSS**, because it allows me to quickly test layouts, colors and spacing. I also use **Framer Motion** to add subtle animations and make the portfolio feel more interactive.

The project is tracked with **Git and GitHub**, so I can save my progress and document my development process.

## Features

The first version includes a hero section, an about section, a project showcase, a featured case study, a process section and a contact section. I also added hover animations, a light and dark mode interaction and scrapbook-inspired visual elements.

This version is still a work in progress, but it already gives me a strong base to build on.

## Getting Started

Clone the project:

```bash
git clone <[repository-url](https://github.com/JasminHachmane/Portfolio-Showcase/)>
```

Go to the project folder:

```bash
cd jasmin-portfolio
```

Install the dependencies:

```bash
npm install
```

Run the project locally:

```bash
npm run dev
```

Open the local server in your browser:

```text
http://localhost:5173/
```

## What I Learned

During this project, I learned how to set up a modern React project with Vite and how to work with different libraries. I also learned how important it is to structure code in components, because it makes the project easier to understand and expand.

I ran into several technical problems, such as running npm commands in the wrong folder, fixing package errors and debugging a white screen in the browser. These moments helped me understand my development environment better.

I also learned that design and development influence each other. A visual idea can look good in a moodboard, but when you build it, you also have to think about usability, responsiveness, spacing and performance.

## Next Steps
