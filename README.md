# Jasmin Portfolio Showcase

A personal showcase portfolio built with React, Tailwind CSS and Framer Motion.

This portfolio was created as part of my ICT Media Design journey and serves as a digital scrapbook that combines design, storytelling and front-end development. It showcases my projects, process, technical growth and creative identity.

## About the Project

Rather than creating a traditional portfolio website, I wanted to build something that felt personal and memorable.

The final concept became a digital scrapbook inspired by vintage archives, paper textures, polaroids and layered design elements. The goal was to create an experience that reflects both my personality and my way of working as a designer and developer.

Throughout the project I continuously refined the design based on feedback, technical limitations and responsive design requirements.

## Technology Stack

This project was built using:

* React
* Vite
* Tailwind CSS
* Framer Motion
* Lucide React
* Git & GitHub
* Vercel

React allowed me to build reusable components, while Tailwind CSS made it easier to experiment with layouts and maintain a consistent design system. Framer Motion was used to create subtle animations that strengthen the scrapbook experience.

## Features

The portfolio includes:

* Interactive scrapbook-inspired homepage
* Featured project case study
* Project overview with detailed project pages
* About section
* Design and development showcase
* Process section
* Responsive layouts for desktop, tablet and mobile
* Animated decorative elements
* Contact section with external links

## What I Learned

This project helped me strengthen both my design and development skills.

During development I learned how to:

* Work with reusable React components
* Structure larger front-end projects
* Create responsive layouts
* Use animation libraries effectively
* Deploy a React application using Vercel
* Balance visual creativity with technical feasibility

One of the biggest lessons was learning that not every design idea translates well into code. Through feedback and iteration, I learned how to adapt concepts into solutions that are both creative and technically realistic.

## Development Process

The portfolio evolved through multiple phases:

1. Research & Inspiration
2. Visual Exploration
3. Concept Development
4. Wireframing
5. Front-end Development
6. Feedback & Iteration
7. Responsive Optimisation
8. Deployment & Final Release

This iterative approach helped transform the portfolio from an idea into a fully deployed digital product.
